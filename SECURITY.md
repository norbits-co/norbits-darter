# 🔐 Security Policy

Dealing with vulnerabilities.

## 📫 Reporting a Vulnerability

Please **do not** open a public issue or PR for a security problem.

Report it privately by emailing contact@norbits.co, or contact [@dwainXDL](https://github.com/dwainXDL) directly.

Include:

- 🧭 What you found and where (URL, page or file)
- 🔁 Steps to reproduce
- 💥 The impact you think it has
- 📎 Screenshots or logs, if they help

## 🚨 Secrets and Private Data

If you find an exposed secret or any private user data:

1. Stop and do not share, copy or use it
2. Report it right away using the contact above
3. Treat any exposed secret as compromised. It must be revoked or rotated

## 🎯 Scope

This policy covers the source in this repository and the sites or services deployed from it.

## 🛡️ Supported Versions

Only the latest code on `main` is maintained.
